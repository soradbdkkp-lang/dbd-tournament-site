# 決定済み事項・未決事項

## 目的

React移行、開発環境、大会ルール、デザインに関する決定済み事項と確認待ち項目を分離して管理する。

## React移行の決定済み事項

| 項目 | 決定内容 |
|---|---|
| フロントエンド | React + Vite + TypeScript |
| パッケージ管理 | npm |
| React Router | 初期導入しない |
| UIライブラリ | 初期導入しない |
| Docker | 初期導入しない |
| 初期ページ | `HomePage`、`RulesPage`、`NotFoundPage` |
| ルールの正本 | `docs` |
| `src/data` | 承認済み内容の表示用コピー |
| 未確定状態 | `status`で管理 |
| 公開可否 | `isPublished`で管理 |
| 旧HTML/CSS | 移行完了まで保持し、削除・改名・移動しない |
| GitHub Pages | 対応を前提とする |
| GitHub Actions | 別フェーズ |
| `about.html` | 当面プレースホルダ |
| `_cdxuser-*` | 後日の退避対象。現時点では削除・移動しない |
| CP932文書 | UTF-8統一は別フェーズ |

## 次フェーズ開始前に必要な決定

React環境導入へ進む前に、最低限以下を確認する。

1. Node.jsの採用バージョン。
2. Node.jsの導入方法。
3. Viteの構築方法。
4. 既存`index.html`の保持方法。
5. 初期ルーティング方式。
6. GitHubリポジトリ名とPages公開URL。
7. 実行を許可するnpmコマンド。

大会ルールの未決事項は、環境導入だけなら保留できる。
ただし`RulesPage`へ公開データを実装する前に解消または公開方針の承認が必要である。
