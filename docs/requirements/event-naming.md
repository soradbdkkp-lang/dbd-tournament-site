# 名称体系

## 目的

サイト、イベントシリーズ、開催回の名称と階層関係を定義し、文書と将来の画面表示で名称を混同しないための正本とする。

## 確定事項

| 区分 | 名称 | 扱い |
|---|---|---|
| サイト・イベントポータル | そらふぇす | サイト全体の名称 |
| 大会シリーズ | ふろぐCup | そらふぇす内で開催する大会シリーズ |
| 現在の開催回 | ふろぐCup Vol.1 | 現在作成中の大会 |

階層関係は、そらふぇす内で大会シリーズのふろぐCupを開催し、現在作成中の大会をふろぐCup Vol.1として扱う。

## 表示責務

- サイト全体のヘッダーでは、サイト名の「そらふぇす」を表示する。
- トップページの大会カード、大会詳細、ルールページでは、対象となる開催回名の「ふろぐCup Vol.1」を表示する。
- サイト名と大会シリーズ名、開催回名を同じ概念として扱わない。

## 将来拡張

- ふろぐCup Vol.2、ふろぐCup Vol.3など、開催回を追加できる前提とする。
- ルールは開催回ごとの差分を管理できる前提とする。
- 開催回IDの具体形式、ルール差分のファイル分割方法、開催回追加時の管理方法は将来検討とする。

## 今回の対象外

- 派生大会・エンジョイ大会は将来検討とし、今回は追加しない。
- 派生大会・エンジョイ大会のデータ、ページ、公開導線、`Coming soon...`表示は作成しない。

## 既存ルール草案の扱い

- `docs/tournament-rule.md`は、現時点ではふろぐCup Vol.1に関係するルール草案として扱う。
- 同文書には未定・検討中の内容が含まれるため、一括して確定事項や公開内容として扱わない。
- 同文書はCP932であるため、文字コード統一フェーズまでは直接編集しない。

## 実装データ

- 名称体系を含む仕様の正本は`docs`とする。
- React移行後に作成する`src/data`は、承認済み内容だけを保持する表示用コピーとする。
- 現時点では`src`と`package.json`が存在しないため、実装データやTypeScript型は作成しない。
