# MAPプール管理

## 目的

大会ごとに使用可能なMAPを管理する。

MAPプールを設定することで極端なMAP相性を緩和し、参加者が事前に対策できる環境を整える。

## 基本ルール

大会で使用されるMAPは、運営が事前に指定したMAPプールから選択される。

MAPプールは大会ごとに変更できる。

室内MAPプールと屋外MAPプールは別管理とする。

## 室内MAP候補

* ギデオン食肉工場
* レリー記念研究所
* ミッドウィッチ小学校
* 酒場（必要に応じて）

## 屋外MAP候補

* ガス・ヘヴン
* アイアンワークス・オブ・ミザリー
* 浄罪の神殿
* サファケーション・ピット
* その他運営指定MAP

## MAP選択権

MAP選択権を獲得したチームは、その試合で使用可能なMAPプールからMAPを選択できる。
