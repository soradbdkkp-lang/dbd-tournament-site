# ふろぐCup Vol.1 キラー制限ルール

## 目的

この文書は、ふろぐCup Vol.1のキラー固有制限ルールを整理する正本docsである。

今回の正本化では、ユーザが2026-06-24に提示した最新ルール本文を最優先する。勝利条件、予選順位、吊り数、死亡処理、意図的な切断、バグ・グリッチ、煽り、異議申し立て、リザルト提出は`docs/requirements/vol1-common-match-rules.md`を参照する。

## 確定事項

### 基本方針

- キラー自体、MAP自体はポイント制にしない。
- キラーとMAPの組み合わせごとに、アドオンポイント上限を決める。
- キラー再使用制限はチーム単位で管理する。
- キラー担当者は固定しない。
- 共通試合判定ルールと重複する内容は、この文書では参照に留める。

### 禁止キラー

| キラー | 扱い |
|---|---|
| スカルマーチャント | 使用禁止 |

### 使用可能キラー

| キラー | 扱い |
|---|---|
| ジェイソン | 使用可能 |

### 調整中キラーではないもの

ジャッジメントは、使用可否が調整中の項目である。ただし「調整中のキラー」としては扱わない。

### キラー使用回数・担当者

- 同一チーム内で、同一大会内の同じキラー再使用は禁止する。
- キラー再使用制限はチーム単位で適用する。
- キラー担当者は固定しない。

### キラーパーク制限

以下のキラーパークは禁止候補として扱う。

| パーク | 状態 |
|---|---|
| 露見する闇 | 禁止候補 |
| 隠れ場なし | 禁止候補 |
| 捕食者 | 禁止候補 |
| 狩りの興奮 | 禁止候補 |
| 幻影の震撼 | 禁止候補 |

アンフォーシーンは、屋内MAPでは使用禁止とする。

死人のスイッチの扱いは以下とする。

| キラー | 死人のスイッチ |
|---|---|
| ナース | 使用可能 |
| ブライト | 使用可能 |
| ヒルビリー | 使用可能 |
| シンギュラリティ | 使用不可 |
| 喰種 | 調整中 |
| その他キラー | 使用可能 |

### MAP制限

- MAPはポイント制ではない。
- MAPは、キラーごとに運営指定MAPプールから選択する。
- MAP再使用禁止はチーム単位で適用する。
- MAPオファリングはキラー、サバイバーともに禁止する。

### アドオン制限

- キラー自体、MAP自体はポイント制にしない。
- キラーとMAPの組み合わせごとにアドオンポイントが決まる。
- アドオンポイント上限は、キラーとMAPの組み合わせごとに設定する。
- 各アドオンのポイントは、レア度ではなく個別性能を基準に設定する。
- 併用禁止アドオンは、キラーとMAPの組み合わせごとに設定する。
- ノーアドオンを選択可能とする。

### キラー側の提出内容

提出対象は以下とする。

- 使用MAP。
- 使用キラー。
- 使用アドオン。

キラーパークは提出対象に含めない。

予選の構成提出期限は、開催2〜3週間前を想定する。正確な提出期限は調整中とする。

応募締切後、ブロック分けと試合順が発表された後に、対戦相手ごとにMAPを選択する。

本戦中の構成提出期限は以下とする。

| 対象 | 提出期限 |
|---|---|
| 準決勝 | 予選終了後の10分休憩終了まで |
| 決勝 | 準決勝終了後の10分休憩終了まで |

構成提出ページはComing soonとする。

将来的には、サイト内でMAP、キラー、アドオンを選択し、画像保存とGoogleフォーム送信を行う想定とする。

送信に失敗した場合は、画像保存も行わず、再送信を促す。

複数回提出された場合は、最新の有効提出を採用する。

### 試合前確認

- 試合開始前に、運営がVCで構成確認を行う。
- キラー側の確認対象は以下とする。

| 確認対象 | 内容 |
|---|---|
| 使用キラー | 禁止キラー、再使用制限 |
| 使用MAP | 運営指定MAPプール、MAP再使用禁止 |
| 使用アドオン | アドオンポイント上限、併用禁止 |
| 使用パーク | キラーパーク制限 |
| オファリング | MAPオファリングを含むオファリング使用有無 |

- 確認後の構成変更は禁止する。
- 確認後に異なる構成で試合を開始した場合は、ペナルティ対象とする。
- 具体的なペナルティ内容は調整中とする。

### キラー側の切断・クラッシュ

- キラーが切断、クラッシュした場合は、運営をVCに呼ぶ。
- サバイバー側は自己判断で切断せず、運営判断を待つ。
- サーバー障害やその他トラブルの場合は、運営判断とする。

#### 無ペナルティ再試合

以下すべてを満たす場合は、無ペナルティ再試合とする。

- キラーがサバイバーを1人も吊っていない。
- 発電機が1台も修理完了していない。
- その試合で1回目の切断・クラッシュである。

無ペナルティ再試合時の構成変更は以下とする。

- キラー側はパーク変更不可。
- サバイバー側はパーク変更可能。

#### ペナルティあり再試合

以下のいずれかに該当する場合は、ペナルティあり再試合とする。

- キラーがサバイバーを1人以上吊った後。
- 発電機が1台以上修理完了した後。
- その試合で2回目以降の切断・クラッシュ。

ペナルティあり再試合時の構成変更と制限は以下とする。

- キラー側は3パークで再試合。
- キラー側はパーク変更不可。
- サバイバー側はパーク変更可能。

### バグ・グリッチ禁止行為

- バグやグリッチの意図的な利用は禁止する。
- キラー固有のバグ、MAP固有のバグ、アドオン固有のバグが疑われる場合は、証拠を添えて運営へ報告する。
- 詳細な共通扱いは`docs/requirements/vol1-common-match-rules.md`を参照する。

### 煽り行為・マナー

煽り行為、過度な挑発、競技進行を妨げる行為は禁止する。

詳細な共通扱いは`docs/requirements/vol1-common-match-rules.md`を参照する。

### 異議申し立て・証拠

キラー側から異議申し立てを行う場合は、試合映像、スクリーンショット、リザルト画面などの証拠を提出する。

詳細な共通扱いは`docs/requirements/vol1-common-match-rules.md`を参照する。

### リザルト提出

キラー側のスコア、吊り数、使用キラー、使用MAP、使用アドオンなど、勝敗判定と構成確認に必要な情報を提出する。

詳細な共通扱いは`docs/requirements/vol1-common-match-rules.md`を参照する。

## 運営メモ

- `docs/tournament-rule.md`は古い草案として履歴参考扱いにする。
- 古い`docs/killer-points.md`、`docs/point-system.md`にはキラー自体をポイント制にする案や同一キラー再使用時の追加ポイント案があるが、最新ルールでは採用しない。
- Vol.1最新ルールでは、キラー自体、MAP自体はポイント制にせず、キラーとMAPの組み合わせごとにアドオンポイント上限を決める。
- ジャッジメントは使用可否が調整中の項目だが、「調整中のキラー」として扱わない。
- キラー固有ルールに共通試合判定ルールを重複記載しすぎず、参照関係で管理する。
