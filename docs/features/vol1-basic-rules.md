# ふろぐCup Vol.1 基本ルール画面

## 目的

現行の静的HTML/CSS/JavaScriptサイトで、ふろぐCup Vol.1の基本ルール、更新履歴、公開状態を参加者へ表示する。

## 実装方式

- 今回はReact、Vite、TypeScriptを導入しない。
- `index.html`から`rules.html`へ大会ルール導線を設ける。
- `rules.html`は画面構造を保持し、基本ルール本文と更新履歴は`rules-data.js`の表示用コピーから描画する。
- `rules.js`はデータ描画、更新通知期間の判定、タブ切替、該当箇所への移動を担当する。
- `style.css`は既存の暗色背景、カードUI、コーラル系アクセントを継承する。
- 既存HTML/CSSは削除、改名、移動しない。

## 公開範囲

| 種別 | 公開状態 | 表示 |
|---|---|---|
| 基本ルール | 公開 | 暫定ルールとして第1章から第12章を表示 |
| サバイバー制限ルール | 準備中 | `現在準備中です`、`ルール確定後に公開します` |
| キラー制限ルール | 準備中 | `現在準備中です`、`ルール確定後に公開します` |

基本ルール本文と初期更新履歴は、2026年6月13日のユーザ指示で公開用草案として承認された内容を正本とする。
既存の`docs/tournament-rule.md`全体を確定扱いにはしない。

## 画面構成

1. パンくず
2. ページタイトル
3. 公開対象、状態、対象、最終更新日のステータスカード
4. Vol.1内のルール種別切替
5. 最新3件の更新履歴
6. 目次
7. 第1章から第12章の章カード

第5章「試合進行」は未確定とし、`未確定`と`日程確定後に記載`を表示する。

## 状態表示

- 通常時は`暫定`を緑で表示する。
- 更新日当日を1日目として、差分日数が0、1、2の場合は`更新あり`をオレンジで表示する。
- 差分日数が3以上の場合は`暫定`へ戻す。
- 未来日付は`更新あり`として扱わない。
- 更新対象のページ状態、章、項目、目次、更新履歴に`更新あり`を表示する。
- 第5章は黄色の`未確定`表示とする。

日付文字列は`YYYY-MM-DD`を分割し、`new Date(year, month - 1, day)`でローカル日付として生成する。

## 更新履歴

更新履歴は日付の降順で最新3件のみ表示する。

| 日付 | 内容 | 対象ID |
|---|---|---|
| 2026-06-13 | 回線切断ルールを修正 | `basic-6-3` |
| 2026-06-10 | 順位決定ルールを追記 | `basic-11-1` |
| 2026-06-08 | 基本ルール草案を公開 | `basic-chapter-1` |

`該当箇所へ`リンクは対象IDへ移動し、移動先を一時的に強調する。

## データ更新

今後の本文修正は原則として`rules-data.js`で行う。

- ルール本文
- 更新履歴
- 章・項目の固定ID

画面構造や動作要件を変更する場合は、この文書と関連ファイルを同じ作業内で更新する。

## レスポンシブとアクセシビリティ

- PCでは目次を左、本文を右に配置する。
- スマホでは目次と本文を1カラムで縦に配置する。
- 状態は色だけでなく文字でも表示する。
- リンクとボタンを用途で使い分ける。
- 章と項目へ`scroll-margin-top`を設定する。
- 主要操作にはキーボードフォーカスを表示する。
- JavaScript無効時は、本文表示にJavaScriptが必要である旨を表示する。

## 対象外

- React、Vite、TypeScriptの導入
- `package.json`、`package-lock.json`、`vite.config.ts`、`src`の作成
- サバイバー制限ルール本文の公開
- キラー制限ルール本文の公開
- 外部ライブラリの追加
