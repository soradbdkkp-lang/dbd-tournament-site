# getdesign実装指示

## 目的

getdesignから取得した具体的な実装指示を、対象画面、適用範囲、適用状況とともに管理する。
`DESIGN.md`は全体方針と索引として維持し、取得した指示の全文はこの文書へ配置する。

## 現在の状態

- getdesign由来の実装指示は未投入である。
- 内容を推測して作成しない。
- 実指示を取得した後、ユーザが内容と公開・実装範囲を確認してから追記する。

## 記録項目

実指示を追加する際は、少なくとも次を記録する。

| 項目 | 内容 |
|---|---|
| 取得日 | `YYYY-MM-DD`形式。取得日が不明な場合は推測せず「未確認」とする |
| 出典 | getdesignから取得したファイル名または識別情報 |
| 対象画面 | HomePage、RulesPageなど |
| 適用範囲 | ページ全体、セクション、コンポーネント、状態など |
| 指示本文 | 取得した具体的な実装指示 |
| 適用状況 | 未適用、一部適用、適用済み、保留 |
| 未適用項目 | 未反映の内容と理由 |
| 実装時の注意点 | 既存仕様、レスポンシブ、アクセシビリティ、権利関係など |
| 関連文書 | `DESIGN.md`、画面仕様、コンポーネント仕様、変更履歴など |

## 適用ルール

- 適用前に`DESIGN.md`、`docs/ui/design-references.md`、対象画面・コンポーネントの既存docsを確認する。
- getdesign指示を本サイトのルール文言や公開データの根拠にしない。
- `DESIGN.md`または既存docsと矛盾する場合は実装せず、矛盾点を整理してユーザへ確認する。
- 指示の対象画面や適用範囲が不明な場合は推測で実装しない。
- 未適用項目を削除せず、保留理由とともに残す。
- 実装へ反映した場合は、適用状況を更新し、変更履歴または該当するdocsへ反映する。
