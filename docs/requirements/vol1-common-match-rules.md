# ふろぐCup Vol.1 共通試合判定ルール

## 目的

この文書は、ふろぐCup Vol.1の共通試合判定ルールを整理する正本docsである。

今回の正本化では、ユーザが2026-06-24に提示した最新ルール本文を最優先する。`docs/tournament-rule.md`は履歴参考として扱い、最新ルールと矛盾する場合は最新ルールを採用する。

サバイバー固有ルールは`docs/requirements/vol1-survivor-rules.md`、キラー固有ルールは`docs/requirements/vol1-killer-rules.md`を参照する。

## 確定事項

### 各試合の勝利条件

各マッチは、まずチーム得点を比較して勝敗を決定する。

| 得点 | 計算方法 |
|---|---|
| キラー得点 | 吊り数（1吊り1Pt、最大12Pt）＋全滅ボーナス（2Pt） |
| サバイバー得点 | 修理完了発電機数（1台1Pt、最大5Pt）＋脱出人数（1人1Pt、最大4Pt） |
| チーム得点 | キラー得点＋サバイバー得点 |

- チーム得点が高い側を、そのマッチの勝者とする。
- チーム得点が同点の場合は、「キラーのゲーム内スコア＋サバイバー4名のうち2番目に低いゲーム内スコア」を比較し、合算値が高い側を勝者とする。
- それでも完全同点の場合は運営判断とする。
- 古い「全滅、吊り数＋修理台数、ゲーム内スコア」の順次判定方式は使用しない。

### 予選順位の判定

予選順位は、以下の4種類の予選Ptをすべて加算した予選総合Ptで決定する。各マッチのチーム得点を、そのまま予選順位Ptとして使用しない。

1. 対戦結果Pt：各マッチの勝利3Pt、敗北0Pt。
2. 吊り数＋修理完了台数Pt：各チームの予選2試合分の「吊り数＋修理完了発電機数」を合算し、ブロック内1位2Pt、2位1Pt、3位0Pt。
3. ゲーム内スコアPt：各試合の「キラーゲーム内スコア＋サバイバー4名のうち2番目に低いゲーム内スコア」を算出し、予選2試合分を合算して、ブロック内1位2Pt、2位1Pt、3位0Pt。
4. シークレットボーナス：MAPボーナス1Pt、キラーボーナス1Pt。同一試合で両方獲得可能とし、予選の対戦勝敗には加算しない。

- 2と3で同数の場合は同順位・同Ptとし、次順位を飛ばす。
- 予選総合Ptが同点の場合は、対戦結果Pt、直接対決、2の実数、3の実数合計の順で比較する。
- 3チーム同点など、直接対決だけでは決定できない場合は次の比較項目へ進む。
- それでも完全同点の場合は運営判断とする。

### 吊り数カウント

| 事象 | 扱い |
|---|---|
| 通常フック吊り | 1吊り |
| 最大吊り数 | 12 |
| 救助されず耐久に入った場合 | 吊り数を1追加 |
| 初吊りからサクリファイスになった場合 | 3吊り扱い |
| 裁きの檻 | 吊り数に加算 |
| ピッグの逆トラバサミ死亡 | 3吊り扱い |
| 呪殺 | 3吊り扱い |
| 立ちメメ | 3吊り扱い |
| 貪られる希望 | 3吊り扱い |
| 怨恨 | 3吊り扱い |
| 終局のメメント | 3吊り扱い |
| 類似の即時死亡、特殊死亡 | 3吊り扱い |
| 失血死 | 全滅扱い。ただし吊り数は追加しない |
| 意図的な切断 | 3吊り扱い |

### 脱出・死亡の扱い

| 事象 | 扱い |
|---|---|
| 通電後のハッチ脱出 | 吊り数を追加しない |
| 通電後のゲート脱出 | 吊り数を追加しない |
| 非通電時のハッチ脱出 | 最後のサバイバーは3吊り扱い、キラー側は全滅扱い、サバイバー側の脱出得点は0Pt。ゲーム内スコアは有効 |
| 非通電時にキラーがハッチを閉鎖 | ゲート戦へ移行しない。最後のサバイバーとキラーは地下室へ集合し、リザルト画面まで進める |
| 通電後のエンドゲームコラプス死 | 吊り数を追加しない |
| 非通電時のエンドゲームコラプス死 | 3吊り扱い、全滅扱い |

### バグ・グリッチ禁止行為

バグやグリッチの使用は禁止する。

#### 既知のバグ・グリッチ

- 既知のバグ・グリッチは、運営が事前に告知する。
- 事前告知されたバグ・グリッチを使用した場合は、ペナルティ対象とする。

#### 未知のバグ・グリッチ

- 意図せず発生した未知のバグ・グリッチは、厳重注意とする。
- 発覚後は、全体に対して使用禁止として告知する。

#### 悪質・意図的な使用

- 悪質または意図的な使用と判断された場合は、運営判断でペナルティを科す。

### 煽り行為・マナー

以下の行為は禁止する。

- 屈伸。
- エモート。
- ライトカチカチ。
- その他、相手を煽る目的の行為。

煽り行為・マナー違反の扱いは以下とする。

- 動画で確認できた場合は、違反側の敗北とする。
- 動画等の証拠がない場合は、厳重注意とする。
- ゲーム内チャットでの身内ノリは避ける。
- 配信コメントでの荒らし、煽りは禁止する。

### 異議申し立て・証拠

- 試合中に起きた出来事への異議申し立ては、次の試合に移る前までに行う。
- 異議申し立てには証拠が必要である。
- 急を要する場合は、VCに運営を呼ぶ。
- スコア違いに関する異議申し立てには、リザルトスクリーンショットが必要である。
- リザルトスクリーンショットが提出されていない場合、スコア違いの異議申し立てはできない。
- 各自録画を推奨する。

### リザルト提出

- 試合終了後、両チームがリザルト画面のスクリーンショットを提出する。
- リザルトスクリーンショットは、スコア確認、異議申し立て対応に使用する。

## 調整中事項

### バグ・グリッチの具体的なペナルティ

以下は調整中である。

- ペナルティの段階。
- 敗北扱い、警告、失格などの適用条件。
- 既知バグ・グリッチの事前告知方法。

### 煽り行為・マナー違反の具体的なペナルティ

以下は調整中である。

- 厳重注意の累積扱い。
- 配信コメント荒らしが関係者以外によるものだった場合の扱い。
- エモートが許可行為か煽り行為か判断が分かれる場合の裁定。

### 異議申し立ての運用詳細

以下は調整中である。

- 提出先。
- 裁定者。
- 証拠の形式。
- 異議申し立て中の試合進行。

### リザルト提出の運用詳細

以下は調整中である。

- 提出先。
- 提出期限。
- 提出漏れがあった場合の扱い。
- スクリーンショット以外の代替証拠の可否。

## 運営メモ

- `docs/tournament-rule.md`は古い草案として履歴参考扱いにする。
- 古い草案では、通電後のエンドゲームコラプス死を吊り数+1としていたが、最新ルールでは吊り数を追加しない。
- 非通電時のハッチ処理は、公開サイトで確定した得点・全滅処理と、ハッチ閉鎖後にゲート戦へ移行せずリザルト画面まで進める手順を正とする。
- 共通試合判定ルールは、サバイバー制限ルール、キラー制限ルールへ重複記載しすぎず、参照関係で管理する。
