# 初期ページ仕様

## 目的

React + Vite + TypeScript移行の最小実装で作成するページと、表示対象外を定義する。

## 対象範囲

初期実装は以下の3ページに限定する。

- `HomePage`
- `RulesPage`
- `NotFoundPage`

キラー、MAP、ポイント、変更履歴、アンケート、対戦表の専用ページは初期実装に含めない。

## 共通要件

- `PageLayout`を通して共通ヘッダー、ナビゲーション、本文領域、フッターを表示する。
- 共通ヘッダーにはサイト名の「そらふぇす」を表示する。
- 大会名はサイト名と分け、対象となるページやカードで開催回名を表示する。
- スマホ1カラムを基本とする。
- 公開する内容は、ユーザが承認した`src/data`の表示用コピーに限定する。
- `isPublished: false`の項目を表示しない。
- 検討中または未定を公開する場合は、状態ラベルを併記する。
- 既存HTML/CSSのルール文言を推測で補完しない。

## HomePage

### 役割

大会の現在状況と主要情報への入口を提供する。

### 初期表示候補

- 現在の開催回名「ふろぐCup Vol.1」
- サイトの説明
- 開催状況
- 開催予定日「2026年9月12日（土）」
- 大会概要
- お知らせ
- `RulesPage`への導線

### 注意事項

- 大会カードを表示する場合は、開催回名として「ふろぐCup Vol.1」を表示する。
- 開催予定日は「開催予定日：2026年9月12日（土）」と表示し、確定を示す表現は使用しない。
- 現行`index.html`の参加人数に関する文言は、正本での確定が確認できるまで確定事項として転記しない。
- アンケート、キラー制限、Discordへのリンクは、リンク先と公開可否が決まるまで無効なリンクとして表示しない。
- 変更履歴への導線は表示方式が決まってから追加する。

## RulesPage

### 役割

承認済みの大会ルールを、カテゴリと状態を明確にして表示する。

対象となる大会名は、開催回名の「ふろぐCup Vol.1」として表示する。
共通ヘッダーには「そらふぇす」、本文主見出しには「ふろぐCup Vol.1 大会ルール」を表示する。
開催予定日は「開催予定日：2026年9月12日（土）」と表示する。

### 初期セクション候補

- 開催予定日
- 基本情報
- 勝敗判定
- 禁止事項
- 検討中事項

実際に表示するセクションは、公開承認された内容だけに限定する。

### 注意事項

- 現行`rules.html`の「ここに記載」は公開データへ移さない。
- `docs/tournament-rule.md`の内容を一括で確定扱いしない。
- 禁止、条件、例外は別の表示要素として識別できるようにする。
- 文書間で矛盾するキラーリミットやポイント制度は、決定まで表示しないか、検討中としての公開承認を得る。

## NotFoundPage

### 役割

定義されていない画面またはURLへ到達した利用者に、トップページへ戻る手段を提供する。

### 初期表示

- ページが見つからない旨
- `HomePage`へ戻る導線

ルーティング方式によって到達条件が変わるため、実装前にURL方式を確定する。

## about.htmlの扱い

- `about.html`は当面プレースホルダとして保持する。
- 初期実装で`AboutPage`は作成しない。
- `about.html`を削除、改名、移動、上書きしない。
- 大会趣旨の公開文言が確定した後、独立ページが必要か再判断する。

## ナビゲーション

初期ナビゲーションには、実在し公開可能なページだけを含める。

- Home
- Rules

`NotFoundPage`はナビゲーションへ含めない。
スマホでの形式は未決であり、初期実装前に縦並びまたは別方式を決定する。

派生大会・エンジョイ大会は今回の対象外とし、ページ、ナビゲーション、カード、`Coming soon...`表示を追加しない。

## 未定・検討中表示

- 未定事項を空欄や仮文言で表示しない。
- 公開承認された未定事項は「未定」ラベルと説明を表示する。
- 公開承認された検討事項は「検討中」ラベルと説明を表示する。
- 非公開の未定事項は画面に出さない。

## アクセシビリティ

- ページごとに1つの主見出しを置く。
- 見出し階層を飛ばさない。
- ナビゲーションと本文領域をセマンティック要素で区別する。
- 状態を色だけで表現しない。
- リンク文言から移動先が分かるようにする。
- キーボード操作で主要導線を利用できるようにする。

## レスポンシブ表示

- スマホでは1カラムを基本とする。
- 本文が横方向へはみ出さないようにする。
- タップ対象を小さくしすぎない。
- PCでは可読幅を維持し、長文が横に広がりすぎないようにする。

## 対象外

初期実装では以下を行わない。

- React Router導入
- UIライブラリ導入
- キラー・MAP画像導入
- 検索・絞り込み
- 管理画面
- 外部API連携
- アンケート送信
- 対戦表
- GitHub Actions設定

## 受け入れ条件

- 3ページの責務が分離されている。
- 公開承認済みの内容だけが表示される。
- 状態ラベルと公開可否が仕様どおりである。
- HomeとRules間を移動できる。
- 未定義の画面からHomeへ戻れる。
- スマホ幅とPC幅で主要情報を読める。
- 旧HTML/CSSが変更されていない。
