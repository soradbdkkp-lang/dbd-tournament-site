# ポイントドラフトシステム

## 目的

強力なキラーやパークへの偏りを抑制し、多様な構成が活躍できる環境を作る。

また、試合前の構成選択にも戦略性を持たせることを目的とする。

## 基本ルール

各チームは試合ごとに規定ポイントを保有する。

キラー、パーク、アドオンにはそれぞれポイントが設定されている。

合計ポイントが上限を超えない範囲で構成を選択する。
