# デザイン参考資料

## 目的

本サイトのデザイン判断で使用する参考資料の役割、参照優先順位、矛盾時の扱いを管理する。
`DESIGN.md`は全体方針と索引として維持し、この文書で参考資料の具体的な位置付けを整理する。

## 現在の参考資料

### `docs/DESIGN-claude.md`

確認結果:

- 温かいクリーム系のキャンバス、編集的な画面構成、セリフ体の大見出し、人間的で落ち着いた印象を中心とする。
- 大きな余白、読み物としての階層、控えめな角丸、暗色面との対比を具体的に記載している。
- 独自フォントやClaude固有のブランド要素を含むため、そのまま本サイトへ転用する仕様書ではない。

主な参照用途:

- フォントと文字階層
- 余白と情報密度
- 雰囲気、世界観、質感
- 画面全体の印象
- 文体トーン
- 過度にならない演出方向

### `docs/DESIGN-cohere.md`

確認結果:

- 白を基調に、深緑、濃紺、黒、コーラル、青などを用途別に整理した配色体系を持つ。
- 背景面、カード面、罫線、フォーカス、エラーなどのカラートークンと用途が具体的である。
- 大型タイポグラフィやCohere固有のフォント、企業向け構成も含むため、そのまま本サイトへ転用する仕様書ではない。

主な参照用途:

- 色遣いと配色
- カラートークン
- 背景色とサーフェス
- 強調色
- 警告色、エラー色、フォーカス色
- 状態色

## 参照優先順位

- 色に関する判断では`docs/DESIGN-cohere.md`を優先する。
- フォント、雰囲気、質感、演出方向では`docs/DESIGN-claude.md`を優先する。
- 本サイト固有の情報設計、状態表示、アクセシビリティ、スマホ優先方針は`DESIGN.md`と既存docsを優先する。
- 参考資料の固有ブランド、固有ロゴ、固有サービス向けUI、独自フォントを推測で採用しない。

## 矛盾時の扱い

現在確認できる主な差異:

- `DESIGN-claude.md`は温かいクリーム系背景とコーラルCTAを中心とする。
- `DESIGN-cohere.md`は白背景と近黒CTAを基本に、深緑・濃紺の大きな面、用途を限定したコーラルを使用する。
- 角丸、CTA形状、見出しの書体とサイズにも差がある。

これらは役割別の参考として扱い、値を混合して正式仕様を推測しない。
同じ判断領域で矛盾する場合、または`DESIGN.md`や既存docsと衝突する場合は、実装せず次をユーザへ提示する。

1. 矛盾する資料と該当箇所
2. 対象画面またはコンポーネント
3. 各案の見た目とアクセシビリティへの影響
4. 推奨案とその理由

## 配置方針

現在、両参考資料は`docs`直下に存在する。
恒久的にはUI資料であることが分かるよう`docs/ui`配下へ整理する案があるが、移動、改名、リンク更新はユーザ承認後に別作業として行う。
現時点では既存ファイルを移動、改名、削除しない。

## getdesign指示との分離

この文書は複数のデザイン参考資料の比較と参照ルールを扱う。
getdesignから取得する画面別・実装別の具体的な指示は、記録項目と適用状況が異なるため、`docs/ui/getdesign-implementation-instructions.md`で別に管理する。

## 画像カード仕様との関係

キラー、MAP、アドオンなどの画像カードに関する共通表示仕様は`docs/ui/image-card-guidelines.md`で管理する。

- カードの余白、文字階層、雰囲気は`docs/DESIGN-claude.md`を参考にする。
- レアリティ背景、選択中、選択不可、使用禁止などの色は`docs/DESIGN-cohere.md`を参考にする。
- サイト固有の状態表示、スマホ優先、色だけに依存しない表示は`DESIGN.md`と`docs/ui/image-card-guidelines.md`を優先する。
- DBD固有のレアリティ色は参考資料だけから確定せず、実画像とのコントラストを確認してユーザ承認後に決定する。
