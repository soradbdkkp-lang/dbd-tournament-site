# ふろぐCup Vol.1 サバイバー制限ルール

## 目的

この文書は、ふろぐCup Vol.1のサバイバー固有制限ルールを整理する正本docsである。

今回の正本化では、ユーザが2026-06-24に提示した最新ルール本文を最優先する。勝利条件、予選順位、吊り数、死亡処理、意図的な切断、バグ・グリッチ、煽り、異議申し立て、リザルト提出は`docs/requirements/vol1-common-match-rules.md`を参照する。

## 確定事項

### 基本方針

- サバイバー側の制限は、過度に強力な構成や重複による偏りを抑えつつ、試合前に確認可能な形で整理する。
- 共通試合判定ルールと重複する内容は、この文書では参照に留める。
- 禁止、制限、例外は公開サイト実装時に参加者が確認しやすい粒度で表示する。

### サバイバーキャラクター

- サバイバーキャラクターの重複は禁止する。
- レジェンダリースキンは別キャラクター扱いとする。

### サバイバーパーク

- サバイバーパークの重複は禁止する。
- 以下のサバイバーパークは使用禁止とする。

| パーク | 扱い |
|---|---|
| 安心感 | 使用禁止 |
| ベビーシッター | 使用禁止 |
| 恵みパーク全般 | 使用禁止 |
| 重責 | 使用禁止 |

### 解放・邪気

解放と邪気は、チーム内でどちらか片方のみ採用可能とする。

### アイテム制限

| アイテム種別 | 扱い |
|---|---|
| 持ち込みアイテム | 全禁止 |
| チェスト入手アイテム | 使用可能 |
| 劇作法など試合中生成アイテム | 使用可能 |
| 鍵 | 持ち込み、チェスト、生成のいずれも使用禁止 |

鍵は入手経路に関わらず使用禁止とする。

### オファリング

- サバイバーのオファリングは全禁止とする。
- MAPオファリングはキラー、サバイバーともに禁止であり、共通扱いは`docs/requirements/vol1-common-match-rules.md`を参照する。

### トーテム制限

- 呪いのトーテムは、発電機1台修理完了まで破壊禁止とする。
- 無力なトーテムは、試合開始直後から破壊可能とする。
- 恵みパークは禁止のため、恵みのトーテム作成は不可とする。

### セノバイト戦の制限

セノバイトの箱を所持した状態で、予想外の展開を使用する行為は禁止する。

### AFC自力脱出の扱い

- サバイバーパーク以外による自力脱出の試行は禁止する。
- 通電後は自力脱出を試みてよい。
- 解放または邪気の使用権がある場合は、自力脱出を試みてよい。
- 解放と邪気の採用制限は、チーム内でどちらか片方のみ採用可能とする。

### ブライト・ヒルビリーへのしゃがみ回避

ブライトの突進攻撃、ヒルビリーのチェンソー攻撃をしゃがんで避けるテクニックは使用可能とする。

### エモート制限

- 板の中央に倒れる際のエモート使用は可能とする。
- ゲート内で倒れる際のエモート使用は可能とする。
- 上記以外のエモートや挑発行為が煽り行為に該当するかは、共通試合判定ルールの煽り行為・マナーを参照する。

### 煽り行為・マナー

煽り行為、過度な挑発、競技進行を妨げる行為は禁止する。

詳細な共通扱いは`docs/requirements/vol1-common-match-rules.md`を参照する。

### 試合前確認

- 試合開始前に、運営がVCで構成確認を行う。
- サバイバー側の確認対象は以下とする。

| 確認対象 | 内容 |
|---|---|
| 使用キャラクター | キャラクター重複、レジェンダリースキン扱い |
| 使用パーク | パーク重複、禁止パーク、解放・邪気の採用制限 |
| アイテム | 持ち込みアイテム禁止、鍵禁止 |
| オファリング | オファリング全禁止 |

- 確認後の構成変更は禁止する。
- 確認後に異なる構成で試合を開始した場合は、ペナルティ対象とする。
- 具体的なペナルティ内容は調整中とする。

### サバイバー側の切断・クラッシュ

- サバイバーが切断、クラッシュした場合は、運営をVCに呼ぶ。
- 味方が落ちた場合でも、他サバイバーは自己判断で切断しない。
- 他サバイバーは行動を止め、運営判断を待つ。
- サーバー障害やその他トラブルの場合は、運営判断とする。

#### 無ペナルティ再試合

以下すべてを満たす場合は、無ペナルティ再試合とする。

- サバイバーが1人も吊られていない。
- 発電機が1台も修理完了していない。
- その試合で1回目の切断・クラッシュである。

無ペナルティ再試合時の構成変更は以下とする。

- サバイバー側はパーク変更不可。
- キラー側はパーク変更可能。

#### ペナルティあり再試合

以下のいずれかに該当する場合は、ペナルティあり再試合とする。

- サバイバーが1人以上吊られた後。
- 発電機が1台以上修理完了した後。
- その試合で2回目以降の切断・クラッシュ。

ペナルティあり再試合時の構成変更と制限は以下とする。

- サバイバー側は全員3パークで再試合。
- サバイバー側はパーク変更不可。
- キラー側はパーク変更可能。

### 異議申し立て・証拠

サバイバー側から異議申し立てを行う場合は、試合映像、スクリーンショット、リザルト画面などの証拠を提出する。

詳細な共通扱いは`docs/requirements/vol1-common-match-rules.md`を参照する。

### リザルト提出

サバイバー側のスコア、発電機修理台数、脱出状況など、勝敗判定に必要な情報を提出する。

詳細な共通扱いは`docs/requirements/vol1-common-match-rules.md`を参照する。

## 調整中事項

### 試合前確認違反のペナルティ

確認後に異なる構成で試合を開始した場合の具体的なペナルティ内容は調整中である。

### サバイバー側の切断・クラッシュ裁定

以下は調整中である。

- サーバー障害時の再試合条件。
- その他トラブル時の再試合条件。
- 切断・クラッシュの回数管理方法。
- 行動停止中に発生したゲーム内進行の扱い。

### 違反時ペナルティ

以下に違反した場合のペナルティは調整中である。

- キャラクター重複。
- パーク重複。
- 禁止パーク使用。
- 解放・邪気の同時採用。
- 鍵の使用。
- オファリング使用。
- トーテム制限違反。
- 予想外の展開の制限違反。

## 運営メモ

- `docs/tournament-rule.md`は古い草案として履歴参考扱いにする。
- 古い草案では、禁止パーク候補に有能の証明、デジャヴ、不動の視力、加速の策略などが含まれていたが、最新ルールでは採用しない。
- 恵みパーク全般は禁止のため、恵みのトーテム作成も不可とする。
- サバイバー固有ルールに共通試合判定ルールを重複記載しすぎず、参照関係で管理する。
